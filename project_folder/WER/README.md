# Word Error Rate (WER)

Навчальний проєкт для обчислення метрики Word Error Rate між двома текстами.

## Структура
- `wer.py` — реалізація алгоритму WER на основі відстані Левенштейна та динамічного програмування.
- `main.py` — читання текстів, запуск обчислення та запис результатів.
- `reference.txt` — еталонний текст (понад 100 слів).
- `hypothesis.txt` — текст для порівняння (понад 100 слів).
- `results.json` — метрики, сформовані після запуску програми.

## Метрики
- `S` — substitutions, заміни;
- `D` — deletions, видалення;
- `I` — insertions, вставлення;
- `N` — кількість слів в еталонному тексті;
- `WER = (S + D + I) / N`.

Перед обчисленням текст переводиться в нижній регістр, а пунктуація не враховується.

## Запуск
У терміналі перейдіть до папки проєкту та виконайте:

```bash
python3 main.py
```

Після запуску програма виведе метрики в термінал і створить або оновить `results.json`.
