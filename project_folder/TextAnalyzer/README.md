

TextAnalyzer — це програма на Python для статистичного аналізу українськомовних текстів.

Програма зчитує текст із файлу text.txt та виконує аналіз слів і літер за допомогою словників, множин і регулярних виразів.


1. Обчислення частоти кожного слова у відсотках.
2. Визначення найкоротших слів.
3. Визначення найдовших слів.
4. Підрахунок кількості унікальних слів.
5. Підрахунок загальної кількості слів.
6. Визначення всіх літер, використаних у тексті.
7. Визначення найчастішої літери.


- main.py — основний програмний код.
- text.txt — текст для аналізу.
- README.md — опис проєкту.


- Python 3
- re — робота з регулярними виразами.
- pathlib — робота з файлами.


1. Завантажити файли проєкту.
2. Переконатися, що Python 3 встановлений.
3. Відкрити термінал у папці проєкту.
4. Виконати команду:

```bash
python3 main.py
```
