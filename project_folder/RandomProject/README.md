# RandomProject — робота з модулем random

## Опис
Програма демонструє використання стандартного модуля `random` у Python.

## Реалізовані завдання
0. Пояснення та демонстрація `random.random()`, `random.randint()` і `random.choice()`.
1. Випадковий вибір одного студента зі списку групи (п'ять повторень).
2. Випадковий вибір п'яти різних студентів із групи.
3. Симуляція 100 і 1000 підкидань монети з підрахунком орла та решки.
4. Гра «Камінь, ножиці, папір» проти комп'ютера.

## Склад групи
У програмі використано список із 21 студента, наданий для виконання завдання.

## Запуск
Потрібен Python 3. У терміналі з папки проєкту виконайте:

```bash
python3 main.py
```

Для гри введіть `1`, `2` або `3`, коли програма попросить зробити вибір.

## Примітка
Результати випадкових виборів і підкидань змінюються під час кожного запуску програми.
